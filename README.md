# CFD室間ネットワーク解析ツール（風量・搬送熱量バランス）

このツールは、FlowDesignerから出力された換気・開口部の解析結果（CSV）と、各室の3D形状データ（STL）を紐づけ、**「どの部屋からどの部屋へ、どれだけの空気と熱（搬送熱量）が移動したか」**を自動で空間認識し、集計・可視化するPythonプログラムです。

## 主な機能

* **3D空間の自動認識**: 各部屋のSTLデータと、開口部の中心座標・法線ベクトルから、隣接する部屋（流出元・流入先）を自動判定します。
* **搬送熱量（移流熱量）の計算**: 空気の移動に伴って運ばれる熱エネルギーを自動計算します。
* **加重平均温度の算出**: 面積（または風量）で加重平均した、物理的実態に即した精度の高い開口部平均温度を算出します。
* **換気境界の自動補正**: FlowDesignerの設定に依存する風量のプラスマイナス（符号）のブレを吸収し、給気は「確実な流入」、排気は「確実な流出」として自動補正します。
* **Grasshopper連携**: 建築3Dモデル（Rhinoceros）から、解析用の部屋別STLを簡単かつ確実に書き出すための専用スクリプトを同梱しています。

## フォルダ構成

```text
heat-balance-from-FD-v4/
├── Rhino_to_STL.gh            # 部屋のSTL書き出し用Grasshopperファイル（室名チェック機能付き）
├── heat_flow.py               # ネットワーク解析・集計プログラム本体
├── requirements.txt           # 必要なPythonライブラリ一覧
└── README.md                  # このドキュメント
```

## 🛠️ 動作環境・必須ライブラリ

* **Python 3.14.5**
* **Rhinoceros 7 / 8** (Grasshopperを使用する場合)
* **FlowDesigner** (解析結果CSVを出力できるバージョン)

Pythonの必須ライブラリ（`pandas`, `trimesh`, `numpy` など）は以下のコマンドでインストールしてください。

```bash
pip install -r requirements.txt
```

## 🚀 使い方

### Step 1: 部屋のSTLデータ作成 (Grasshopper)
1. Rhinocerosで建物のモデルを開きます。
2. 部屋のボリュームを閉じた立体形状として作成します。
3. `Rhino_to_STL.gh` を開きます。
4. 1~4の順に操作します
   <img width="1439" height="1078" alt="image" src="https://github.com/user-attachments/assets/a3b87846-aaf9-4183-b3e0-1ee3d678116a" />
   1. 部屋ボリュームを指定
      * Rhinoで作成したボリュームをBrepに入力（右クリック → Set Multiple Breps）
   2. 番号に対応する部屋を確認
      * スライダーを動かすとRhino上でその番号の部屋が表示されます。
      * 中央のパネルにオブジェクト番号の範囲が表示されます。スライダーでその範囲を順番に表示し、全ての部屋が読み込めているかを確認してください。
   3. 番号と室名を紐づけ
      * 左側のパネルを編集（ダブルクリック）し、2で確認したオブジェクト番号の順に室名を全て記入してください。
      * 例えばスライダーを0にしたときに表示されている部屋の名前は第0行（上から1行目）、スライダーを10にしたときに表示されている部屋の名前は第10行（上から11行目）になります。
      * 室名を入力すると、右側のパネルに「現在表示中の部屋は『LDK』です。」のように表示されるので、この表示とRhino上でプレビューされている部屋が対応しているか確認してください。
   4. STL形式で書き出し
      * 左側のパネルに、STLファイルを書き出すフォルダのパスを入力します。パスが見つからない場合エラーとなります。
      * 「Trueにして実行」のトグルをダブルクリックしてTrueにすると書き出しを実行します。
      * 書き出しが終了したら再度ダブルクリックしFalseに戻すことを推奨します。
6. 問題なければ、指定したフォルダに各部屋の `.stl` ファイルを書き出します。
    * 部屋のSTLは完全に閉じている（Closed Mesh）必要があります。Grasshopper側でエラーが出た場合はモデルを確認してください。

### Step 2: FlowDesignerでの解析とCSV出力
1. FlowDesignerでCFD解析を実行します。
2. 吹き出し口、吸い込み口、ファンパネル、開口・圧損、領域指定などの室の境界にあるパネルについて、「流量」と「温度」をCSV出力します。このとき要素単位、オブジェクトごとにファイルを分けて出力します。

### Step 3: Webアプリでの解析・集計
1. 本ツールのURL（Streamlit Community Cloudのページ）にブラウザでアクセスします。
   [CFD搬送熱量分析ツール（Streamlitに遷移）](https://heat-balance-from-fd-v4-a6z3y84djgsf8mtygwu6q5.streamlit.app/)
2. 画面のアップローダーに、以下のファイルをそれぞれドラッグ＆ドロップします。
   * Step 1で作成した **すべてのSTLファイル**（複数選択して一括アップロード）
   * Step 2で出力した **すべてのCSVファイル**（複数選択して一括アップロード）
3. ファイルが揃うと自動的に計算が開始され、画面上にリアルタイムで結果が表示されます。

## 📊 出力されるデータ

プログラムの実行が完了すると、以下のデータが出力されます。

1. **グラフ**
   * 空気による搬送熱量の収支が正の室と負の室をそれぞれ積み上げたグラフを表示します。
2. **集計表 (画面表示 ＆ CSV保存)**
   * 開口部が面する部屋の判定結果（Plus room/Minus room）
   * 加重平均温度 [℃]
   * 流入/流出風量 [m3/h]
   * 移動熱量 [W]
